about=This is a fork of Memory Layer Saver (https://github.com/YoannQDQ/qgis-memory-layer-saver), by Chris Crook and Yoann Quenach de Quivillic. Please report problems with this version to the fork, not to the original authors.
 Makes memory layers persistent so that they are restored when a project is closed and reopened.
 The memory provider data is streamed in a portable binary format (QDataStream) and embedded
 in the project attachments (inside the qgz archive, or in attachments.zip for unzipped projects).
